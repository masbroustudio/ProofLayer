3-Stop Code Reference Route

The core architecture is isolated across typed monorepo packages. Inspect these files to verify implementation:

Stop 1: Deterministic Invariant Compiler packages/core/src/evaluator.ts

Evaluates structured AST rules in memory (eq, neq, gt, lte, regex, not_regex). Fails closed immediately on missing fields. Guarantees sub-millisecond execution without external LLM token costs.

Stop 2: Fastify Zero-Trust Interceptor & SQLite WAL packages/server/src/server.ts

Proxies tool calls, enforces multi-agent provenance tokens, calculates canonical SHA-256 payload digests, persists records to local SQLite WAL via @libsql/client, and broadcasts live SSE telemetry.

Stop 3: Interactive React Flow Evidence DAG & Dual-Pane Drawer packages/studio/src/components/EvidenceGraph.tsx

Renders live execution lineage. Clicking any node slides open the dual-pane inspector displaying canonical raw JSON alongside the cryptographic Merkle lineage tree.
