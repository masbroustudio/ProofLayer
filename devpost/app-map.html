App Overview

ProofLayer intercepts autonomous multi-agent tool requests at the Model Context Protocol (MCP) boundary, evaluates deterministic AST invariants in <0.05ms at $0 runtime token cost, enforces dual-signature human authorization, and emits an immutable Merkle Evidence DAG.

3-Stop Code Reference Route

  • Stop 1: Deterministic Invariant Evaluator

    Location: packages/core/src/evaluator.ts → evaluateInvariants()

    Evaluates structured AST rules in memory. Fails closed immediately on missing fields. Guarantees sub-millisecond execution without external LLM token costs.

  • Stop 2: Fastify REST & SSE Telemetry Server

    Location: packages/server/src/server.ts → /api/interceptor/propose

    Intercepts tool proposals, computes canonical SHA-256 payload hashes, stores records in local SQLite WAL via @libsql/client, and broadcasts real-time events over SSE.

  • Stop 3: Interactive React Flow DAG & Dual-Pane Drawer

    Location: packages/studio/src/components/EvidenceGraph.tsx & DualPaneDrawer.tsx

    Renders live execution lineage. Clicking any node opens the dual-pane inspector displaying canonical raw JSON alongside the cryptographic Merkle lineage tree.

To Change This, Start Here

Add a new policy rule: Open packages/server/src/db/client.ts and update seedDefaultPolicies() with custom invariant conditions.

Add a protected tool target: Open packages/server/src/server.ts and add a handler to mockTools.

Adjust node styling or colors: Open packages/studio/src/components/EvidenceNodeComponent.tsx.

A Practice to Reuse

Before writing a single line of application code, we authored 20 tests verifying canonical JSON serialization, HMAC Anti-TOCTOU hash matching, multi-agent provenance hierarchy, and sub-millisecond latency.
